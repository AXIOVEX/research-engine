Second-review sampling (RT-4)

Decisions are sampled deterministically (registered fraction 10%, seeded) for independent second review. Current window: 1 review, 0 disagreements. A reviewed window of 5+ with zero disagreements is flagged as a rubber-stamp anomaly — a queue that never disagrees is treated like a control that never fails. Anomaly: none (window below the minimum of 5).
