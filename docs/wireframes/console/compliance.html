open gap — §3.13.11 FIPS-validated cryptographic modules (SP 800-171 §3.13.11)

The platform's cryptographic inventory (crypto-inventory.md, T549) lists 12 operations — ledger hashing and signing, checkpoints, actor intent signatures, delegated-custody signing, OIDC/SAML verification, PKCE, API-key hashing, fingerprints. FIPS 140-3 validated: 0 of 12. Every implementation is capable and none is a validated module.

Consequence, stated plainly: a deployment that must satisfy §3.13.11 for CUI today cannot point at any row of the inventory. The self-hosted shape is the capable CUI path meanwhile; closing this gap is a cross-repo (Axiomere) decision, not a console setting.
