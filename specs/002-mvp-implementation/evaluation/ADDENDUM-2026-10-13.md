# Addendum to the Phase 7 Evaluation Report — 2026-10-13

The evaluation report beside this file (`EVALUATION-REPORT.md`) is a frozen
record and is not edited. One of its statements is no longer true; this
addendum records the correction, under the same append-only discipline the
report itself follows.

**What the report says.** The report states twice that the evaluation
bundle's second version (bundle-v2) is anchored nowhere: in its friction list
(item 3, "The anchor binds bundle-v1, not bundle-v2 … v2's own bundle hash is
anchored nowhere") and in item 9 ("Bundle-v2's own hash is anchored nowhere").
On the report's own account, an auditor could verify v2's contents standalone
and its registration against the public record, but v2 as an artifact was
self-attested.

**What has changed.** Since the report was written, the same study was
registered on the Open Science Framework (Spec 010, 2026-10-12): OSF project
[dvrew](https://osf.io/dvrew/), public registration
[84dk7](https://osf.io/84dk7/), DOI
[10.17605/OSF.IO/84DK7](https://doi.org/10.17605/OSF.IO/84DK7). The
registration record itself states bundle-v2's bundle hash and checkpoint
root. During the records check of 2026-10-13 (red-team finding RTE-24), the
registration's files were compared with bundle-v2 file by file: all 13 files
are byte-identical. Bundle-v2's hash is therefore anchored on a second,
independent public record, and the report's "anchored nowhere" statement is
stale.

Nothing else in the report is affected. Its verdicts, its K-criterion
results, and its remaining stated limitations stand as written.
