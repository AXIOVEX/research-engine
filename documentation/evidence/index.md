# The evidence base

Defensibility is a claim about this engine, so here is its record —
including the outcomes that are not wins. Every study below was
registered before it ran, and every artifact is externally anchored;
the records stand on their own without the engine.

| Study | Run | Outcome |
|---|---|---|
| [Worked study: 2026 AI-mathematics claims](math-study.md) | VALID | 1 supported, 2 **contested**, 2 **inconclusive**, plus a reliability seed resolved false |
| [Phase 7 evaluation](phase7-evaluation.md) | VALID | 2 supported, 1 contradicted, 2 inconclusive; kill criteria K1–K5 all passed — one only after the evaluation caught a real verifier defect |
| [Phase 5 demonstration](demo-study.md) | **INVALID** | No verdicts issued — the swap control was a no-op on a single-actor ledger, and the machinery said so |

Two disciplines run through all three:

- **Predictions precede outcomes.** The Phase 7 corpus recorded its
  expected verdicts before the freeze; the math study's claims were
  registered with falsifiers before evidence was weighed.
- **Defects are disclosed in place.** The INVALID demo is deposited
  publicly, labelled INVALID. The verifier gap the Phase 7 evaluation
  found is documented in its report, next to the pass it delayed.
